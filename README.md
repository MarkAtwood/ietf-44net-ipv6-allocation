# draft-ursini-44net-ipv6-allocation

Unofficial working copy of Preston Ursini's Internet-Draft
"Reservation of IPv6 Address Block 44::/16 for Amateur Radio Digital
Communications (44Net)".

- Datatracker: https://datatracker.ietf.org/doc/draft-ursini-44net-ipv6-allocation/
- The -00 and -01 commits are the XML sources as posted to the IETF
  archive, committed under the author's name and posting dates; tags
  mark each revision. This repository is maintained by Mark Atwood
  and is not the author's own repository. Changes after -01 are
  proposals, not the author's text.

Build: `xml2rfc --text --html draft-ursini-44net-ipv6-allocation.xml`
